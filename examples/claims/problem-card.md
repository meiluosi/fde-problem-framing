# 车险材料核对｜问题定义卡 v0.1
草稿；建议 **Investigate**。业务负责人待确认，尚无上线决定。

1. **问题**：据用户教学情境 [C01]，理赔员跨三个系统核对材料约20分钟，占总处理时长一半；重复核对与担责可能相关，缺现场日志验证。
2. **为何现在**：原提案称案量同比增18%、编制不变、电子化提高 [C01]，须核验适用周期及人群。
3. **候选干预**：先比较材料一次收齐、统一字段视图/规则校验与 AI 抽取辅助；若语义理解是剩余瓶颈，再试侧边建议工具，保留人工复核。
4. **本期不做**：自动结案、拒赔判定、人伤案件和核心系统改造；手写件是否纳入辅助待验证，不能从全量效果分母消失。
5. **成功口径**：22分钟是待核验目标；在其他20分钟不变时要求核对降至2分钟（90%降幅）。记录字段质量/异常召回、有效采用与复核耗时、全量端到端时长及差错；18/23需定义稳定窗口。基线及护栏阈值待确认。
6. **风险与退出**：35%是定损单比例，非已知案件比例；200单代表性未明。严重漏检、越权或复核失效时停止试验并回退人工，具体判定标准由业务/风险岗位确认。
7. **配合与下一步**：建议业务与数据岗位澄清时长和手写分母，分层选样；原计划200单、三位评判者和IT两周同步均待确认。完成口径与对照验证后重评。
