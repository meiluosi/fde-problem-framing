# 生产规范查阅与经验协作｜问题定义卡 v0.2.2

**建议：Investigate；优先核验非AI改善机会。** 改善价值待验证；干预方向未定；尚未达到实施准备度。撤回此前对整个场景的Stop-Defer建议。

1. **问题草稿**：生产人员查规范以确认参数、适用条件及阶段控制要求。用户逐段读PDF仍可能找不到相关内容，随后请教经验人员；专家通常可答复，分歧讨论被用户认为必要有效。待诊断机会在前置查阅与求助准备，不能把专家讨论本身判为缺陷，也不能认定规范必有或必无答案。
2. **为何现在**：用户认为可能值得用规则等方式改善；尚无查阅负担、频次或投入收益基线。该意见支持继续探索，不证明立项价值。
3. **候选干预**：阶段/主题索引帮助定位已有依据；覆盖说明及求助路径帮助识别资料边界；现场条件清单帮助准备专业求助。均为非AI候选，需核验内容可整理性与维护成本。必要时再评估AI增量价值，不默认替代专家。
4. **保留与边界**：保留有效的经验判断及分歧讨论。当前只定义问题和最小验证，不建系统，不把经验强行写成通用生产规则，不自动确定参数。
5. **成功条件**：下一步明确一个希望改善的前置结果及其证据；未来方案按同口径检查查阅/求助准备负担、正确完成与专业复核，不以减少会议数量为默认目标。基线与目标待定。
6. **风险与退出**：索引可能无法解决正文未覆盖；覆盖标记不得把搜索未命中当作不存在；整理维护可能抵消收益。证据不足继续Investigate，不能整体Stop-Defer；只有有依据的否定或不可行条件才暂缓对应范围。
7. **最小下一步**：先请用户指出最希望改变的前置结果，再用一个最近任务核对现有负担、资料覆盖与非AI候选可行性。拟由用户/资料负责人校准，责任及期限待确认。
