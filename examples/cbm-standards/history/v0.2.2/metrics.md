# 两类验收不能混用

## 当前：问题定义Skill质量
核对实际产物能否准确表达任务与完成要求、追问关键未知、列出可反驳原因、区分陈述与实测，并形成有边界的下一步。没有合理样本与评分，不报总体通过率。

## 后续方案：指标候选，尚未测量
| 层 | 候选指标 | 因果限制 |
|---|---|---|
| 技术 | 条款定位、上下文和适用条件提取质量 | 只在对应干预获准后测；不等于Skill质量 |
| 使用 | 有效查阅任务完成、返查和专业复核负担 | 打开文件或得到流畅答案不代表完成 |
| 业务 | 同口径的查阅至确认可用依据的总时间 | 不能直接换算增产或事故减少 |
| 护栏 | 编条款、错范围、未经复核的操作依据 | 严重错误单独审查，责任及停止线待确认 |

技术质量 → 更少返查且能完成任务 → 净时间改善，仅是待验证因果链。全部基线与目标待定，失败任务不剔除；未提供任何实测效果。
