# 问题定义审查
建议 Investigate，保留标准检索方向，尚不支持“AI能显著提效”或“可直接指导操作”。

| 发现 | 证据/影响 | 修订 |
|---|---|---|
| 将找标准与答条款混成一个成功指标 | 本轮只有元数据；条款任务没有完成 | 按层级分别报成功与缺口 |
| 检索命中不等于版本正确 | STD01/08、STD05/06有替代，STD07已废止 | 增状态与时点核验、旧版历史标签 |
| 标准对象不同仍可能题名相近 | STD02范围区分井型；STD04为设计文件 | 先记录工程阶段、井型、地区和用途 |
| 非AI比较可能缺席 | 可用目录与关键词解决部分候选定位 | 目录/全文/AI同题对照，不预定AI胜出 |
| 用户经历被误当答案已确认 | 用户只说能评判，尚未回复具体题目 | 每题待评审，不写客户确认或真实试点 |
| 模拟访谈污染证据 | ramp corrections明示虚构 | 保留来源性质，不计一线证据 |

保留：四岗位、可追溯引用、人工专业判断。下一步为用户校题和取得合法全文，不是增加更多未经验证的标准列表。
