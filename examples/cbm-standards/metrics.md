# 指标字典（阈值和基线待确认）

| 层 | 指标/分母 | 获取方法 | 因果边界 |
|---|---|---|---|
| 技术 | 正确标准与版本任务/全部需定位标准任务 | 领域评审判定；允许多个合理候选 | 文件命中非问题已解决 |
| 技术 | 已有正文支持且定位正确的条款回答/全部条款任务 | 核对实际正文、条号/页码/版本 | 无正文不从分母删除 |
| 技术 | 正确识别范围/版本风险的题/相应风险题 | 分错误类型评审 | 严重错不被均值淹没 |
| 使用 | 无需额外求助完成有效查找的任务/全部任务 | 观察与任务回放 | 拒答必要但不计业务完成 |
| 使用 | 用户核验分钟/任务；回退与返查次数 | 同一计时规则，失败含在内 | 生成快但核验慢可能无收益 |
| 业务 | 获得可用依据的端到端时间，均值/中位数/尾部 | 对照当前方式，按岗位/题型分层 | 不直接推增产、施工合规或事故下降 |
| 护栏 | 编条款、旧版冒充现行、错范围、资料越权事件 | 逐题审阅 | 任一严重事件暂停相关回答方式并修订 |

覆盖、版本、条款与拒答质量分别报；目录成功率、全文成功率、AI回答成功率不能合并成“准确率”。安全停止规则是本轮提议，需业务方确认。公开演练耗时含工具与网络，不作生产人员基线。


## 2026-10-19 专家方向校准
用户原话：“已知要查什么，但难找到具体条款或判断适用工况”。据此优先验证条款定位、上下文完整性和适用条件识别，目录命中不能算任务完成。此反馈不证明具体耗时、收益或四岗位题目均真实；未取得现场测量。
