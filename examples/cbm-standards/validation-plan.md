# 当前最小验证计划｜v0.3.0

本轮聊天已足以形成定义草稿，无需继续确认专家讨论是否有效。价值Unknown、非AI候选、Investigate。

1. 用户先选一个希望改善的前置结果；如果暂不补资料，直接交付问题卡与本计划。
2. 建议用户/资料岗位回放一件近期查阅：具体问题、所用文件、查找过程、专家最后依据。区分没找到与专业确认未覆盖；记录真实负担，未计时不能估造分钟数。
3. 仅在有负担线索时比较索引/覆盖说明/清单与现状；先确认可整理性、维护和复核成本，不直接开发工具。

重评：有证据支持简单方法且具备限定验证条件，可Proceed至该验证；有反证说明该环节净价值不足，Stop-Defer该环节；仍有可消除的关键未知则指定下一证据。建议责任与期限待确认。专家有效流程保留，不把减少讨论次数当默认目标。

Skill测试与上述业务验证分开。多轮回放检查不重复提问、不扩大结论范围、不迎合翻转与按时交付草稿；测试结果不证明规则方案的现场效果。历史计划见 [快照](history/v0.2.2/validation-plan.md)。
