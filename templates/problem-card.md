# 问题定义卡｜场景名｜版本/日期
文档状态：草稿/已确认；决策岗位及确认状态。

决策摘要：价值判断 Supported / Unknown / Unsupported；干预方向及验证状态；推进状态 Proceed / Investigate / Stop-Defer；所针对环节与下一阶段。Non-AI仅表示方向。

1. **问题**：谁在什么任务中有何损失或可验证改善机会；事实与来源、未知分开。
2. **为什么现在**：变化、机会成本与证据；没有证据就待核验。
3. **候选干预**：最小范围及因果假设；比较现状与简单替代，不默认AI。
4. **本期不做**：对象、流程、自动化权限和排除范围。
5. **怎么算成功**：同口径基线→目标；技术/使用/业务及护栏，引用指标字典。
6. **风险与退出**：关键假设、覆盖盲区、停止/回退条件。
7. **需要配合**：证据、岗位、期限待确认、下一次决策条件。

依据：来源/底稿/验证计划路径。摘要以一页可读为目标，细节移至底稿。
