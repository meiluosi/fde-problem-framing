# 05｜路由：煤层气行业入门问题

用户想快速了解行业如何赚钱、有哪些环节，但没有具体客户问题。这属于行业入门/全行业机会扫描，超出本 skill 的适用范围；不要硬套一张 FDE 问题卡，也不需要先追问客户流程。

**建议路由：** 直接提供一份简短行业概览，按价值链说明资源勘查与评价、勘探开发/钻完井、压裂改造、排采生产、集输利用与销售服务等环节，并区分谁投入资本、谁承担作业风险、谁可能获得产品收入或服务收入。把盈利方式写成需要后续核验的商业模式概览，不给无来源的毛利率、投资回报或当前市场排名。

如果用户随后要为某家公司、项目或岗位定义具体问题，再返回本 skill：选定一个真实任务并澄清提出者、使用者、受影响者、决策者和可观察损失。需要当前市场规模、价格、政策或公司数据时，另行使用可靠的时效性来源；本轮离线输入不包含这些证据。
