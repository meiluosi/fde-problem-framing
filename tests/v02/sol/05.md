# 任务5｜行业入门路由

这是行业入门需求，超出本Skill的具体客户问题定义范围；不强制填写问题卡，也不追问客户痛点。路由到一般行业介绍；若已有fde-ramp能力，可交给它做行业价值链与商业模式入门，但本次未读取或假定该能力可用。

面向用户的实际回复：可以先按“资源评价与勘查→钻完井→压裂改造→排采→集输处理→销售利用”了解业务链条。开采经营者主要通过把可售气卖给下游获得收入，相关服务企业则按地质、工程、设备、施工或运维服务收费。理解赚钱机制时，先看产气量、售价、建设投入、运营成本和产气持续性如何共同影响回报；具体盈利水平与政策条件需另找证据。当前只是概览，不对具体项目盈利作判断。

路由建议：Stop-Defer本Skill的问题定义流程，继续一般行业入门说明；当用户提出某个客户、岗位或具体工作阻碍时，再进入需求澄清。这里停止的是不适用的定义流程，并非停止帮助用户。
