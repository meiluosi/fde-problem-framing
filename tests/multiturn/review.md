# 人工审阅：保留失败，不以总通过率掩盖

主审读取全部14条实际回复。第一批8轮发生在收敛规则初版，随后针对观察到的失败修改dialogue与decision，再用新上下文做2轮定向复测。

| 场景/轮次 | 实际观察 | 判断 |
|---|---|---|
| 煤层气1 | 任务、完成要求、Unknown与候选分开；提出实例问题 | 支持当前行为，回复仍较长 |
| 煤层气2 | 用户已说主要经验判断，仍问最近一次是否主要经验判断 | **失败：重复确认** |
| 煤层气3 | 承认重复；保留专家流程，但把未提出改变的专家环节标Stop-Defer | **失败：给保留环节强行作暂缓决定**；未整体否定查阅 |
| 煤层气4 | 按要求交付定义与最小验证，不再追加问题；未将用户意愿当收益 | 支持收敛与证据边界 |
| 客服1—2 | 追问后依据转派观察改范围；保留回答环节，交付草稿，无新增问题 | 支持跨场景迁移；样本观察没有冒充全量 |
| 问数1—2 | 两种口径可共存；先治理与权限，保留分析师，按要求出卡 | 支持三字段与收敛；未宣称AI解决权限 |
| 定向复测1 | 未重问已知经验来源；问具体生产阶段与参数 | 修正后未观察重复确认 |
| 定向复测2 | 三字段只针对前置查阅，专家讨论作为保留范围，无Stop-Defer；无更多问题 | 修正后未观察强行给保留环节赋状态；Unknown保持 |

修订：禁止以“最近一次”包装同一已答结论；实例核验需指明新证据用途。未提出改变的保留环节只记范围约束，不填推进状态。

限制：2轮定向复测不是完整4轮重跑；随后补做完整四轮复测，见下文；没有跨模型稳定性结论。初始失败仍然计入记录，不声称10轮全部通过。完整原序列、更多角色与拒绝提供证据情境应继续回归。

## 完整四轮复测（同一原始输入序列，新的独立上下文）
1. 任务、完成要求、三个字段分开；无捏造损失。
2. 再次问经验人员是否找到条款或主要现场判断：**重复确认仍出现，未稳定解决**。
3. 承认重复并保留专家环节；未强行赋Stop-Defer，未否定前置改善。
4. 用户无更多数据时交付草稿与最小验证，不再追加问题；保留Unknown与非AI候选，未迎合为已证明收益。

结论：三字段、范围保留和按要求交付在这些输出中可见；重复追问仍是已知行为缺陷。不能报告全部回放通过。本版作为验证版发布，后续优先扩大多轮状态更新测试，而不是仅添加更多提醒。
