# 顺序多轮回放协议

执行者只读SKILL与必要引用；第一轮仅见第一条用户输入，每轮实际回复落盘后才收到下一条输入。不预先提供后续事实、预期答案或评分表，不读examples/tests。不同场景用独立上下文；不联网、不访问客户、不开发系统。

本轮由人工主审依据原始输入检查实际回复；没有自动语义评分。测试记录包括逐轮用户输入、回复及主审判断。代理接收的业务消息为合成回放/用户经历改写，不能当作新现场证据。

评审项：已回答问题不重复；假设随证据调整；不从局部有效整体否定；不因用户反对假定收益；三个决策字段不混；可交付时收敛；不执行下游实施。严重失败单列，不能用输出简短等优点抵消。

静态单元测试与此回放分开。单次三场景不证明跨模型或真实客户效果；增补案例需保存版本与完整输出，不能只保留最后一轮成功回答。
